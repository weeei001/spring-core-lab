## 回歸案例與自動化方案

- 原有問題的重現：任務查詢失敗時，原 `TaskDrawer` 以 `task.data == null` 顯示找不到任務。TD-10 要求網路或伺服器失敗改顯示載入失敗與重試。
- 離開確認的回歸：Ant Design `Typography.editable` 在失焦時自動儲存，會讓 TD-07 的導頁動作先寫入再確認。共用內容改用明確儲存／取消；驗收須確認放棄時沒有欄位更新請求。
- 未新增套件或測試框架。本機以 Node 內建 `assert` 直接檢查 `navigation.ts`，13 個斷言通過：拒絕不合法來源、保留站內路徑、建立完整頁連結及還原來源參數。這不涵蓋 React 互動。
- 若要自動化 TD-07／08／10，最小建議為 devDependencies `vitest`、`jsdom`、`@testing-library/react`，分別提供測試執行、DOM 與實際元件互動；以現有 React Router 建立記憶體路由，只模擬不可用的 HTTP。尚未核准、未安裝，也沒有宣稱存在自動化回歸覆蓋。
